## 怎么用这份清单

- 两条工作流先各扫一遍「工作流总览」表，选一条路线；中途按环节替换到另一条也顺（两页章节一一对应）。
- 按「先补短板」采购：多数人的第一笔投入顺序是收音 → 灯光 → 相机（见[《拍摄与制作》](../docs/methods/production.md)§4）。
- 工具数量越少越好：一项任务保留一个主力工具，跑顺流程再添置第二个。
- 涉及付费的，先用免费档跑通一条完整内容，再决定升级。
