## Preface

Single-point tips for video creation are never in short supply. What is missing is the skeleton that organizes them, and one complete route from "I want to make videos" to "producing consistently." This repository adds that skeleton: knowledge laid out in the order real creation happens, with methods, steps and acceptance bars at every stage. See the [Preface](docs/preface.md) for the full story.

## What this is

An open-source handbook set covering the full video-creation lifecycle:

- **It explains both the "how" and the "why"**, without platitudes; numbers and platform rules come with ranges, definitions and the date they were last checked.
- **Every external link is verified one by one** (verified before release, then re-checked weekly by CI).
- **Structured by design**: method domains and production methods each have one job, cross-referencing instead of repeating. See [About This Repo](docs/meta/design.md) for the map and long-term plan.
