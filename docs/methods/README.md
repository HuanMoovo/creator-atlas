# Creator Atlas · 方法域

> 七个方法域按真实创作顺序排列，构成从想法到收入的完整链路。每页统一七节结构，其中「验收标准」就是过关线；配套[制作方法](../genres/README.md)给出各内容形态的做法要点。

## 创作链路

| 顺序 | 方法域 | 一句话 | 主要交接物 |
| --- | --- | --- | --- |
| 1 | [定位与选题](positioning.md) | 决定做什么、给谁看 | 一句话定位、选题库 |
| 2 | [脚本与叙事](script.md) | 把想法变成结构与台词 | 脚本、分镜表 |
| 3 | [拍摄与制作](production.md) | 把脚本变成可用素材 | 素材、B-roll |
| 4 | [剪辑与后期](editing.md) | 把素材变成成片 | 成片、字幕 |
| 5 | [包装与分发](packaging.md) | 让内容被点开、被看见 | 标题、封面、发布 |
| 6 | [增长与复盘](growth.md) | 用数据找问题、迭代 | 复盘记录、实验结论 |
| 7 | [变现与经营](monetization.md) | 让创作可持续 | 收入结构、报价 |

## 怎么用

- **新项目**：从第 1 页顺序读，每页「验收标准」通过后进入下一环。
- **已有频道**：用每页「常见错误」清单对照自查，缺什么补什么。
- **团队**：按[角色与技能地图](../start/roles-skills.md)把方法域映射到岗位分工。
