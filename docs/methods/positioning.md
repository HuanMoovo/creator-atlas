# Creator Atlas · 方法域 · 定位与选题（Positioning & Topic Selection）

> 定位：本页解决「做什么视频、给谁看、凭什么被看见」。它排在创作链路最前面，因为它决定后面所有环节的上限。
> 配套：《脚本与叙事》《包装与分发》《增长与复盘》，以及 `docs/genres/`（各类型的选题惯例）。

## 1. 这个环节解决什么问题

一个成立的说法：**想法决定一条视频的上限，执行决定能不能摸到上限。** 拍摄与剪辑再精致，也救不回一个没人想点的选题。

这个环节要解决的四个具体问题：

1. **没方向**：不知道拍什么、给谁看；跟风换来的是同质化和零积累。
2. **有方向但没选题**：方向正确，但每次开拍前临时抓题材，质量与节奏都不稳定。
3. **有选题但没人看**：内容不差，就是点不动，多半是选题与「可包装性」脱节。
4. **涨粉与播放脱节**：播放有了粉丝不涨，或只有老观众在看。

定位与选题的标准产出是两份资产：**一句话定位**（写给谁、提供什么、凭什么）与**选题库**（持续更新的 30-50 个候选选题，每个都带标题与封面思路）。

## 2. 核心框架

### 2.1 受众三层模型：核心、偶尔、新增

把大概率会看到这条视频的人分三层（公开分享里常用的分法）：

| 层 | 是谁 | 对选题的意义 |
| --- | --- | --- |
| 核心观众 | 每期都看、认人 | 保证基本盘；但只服务他们会锁死播放量上限 |
| 偶尔观众 | 认识你，看题材决定看不看 | 增长主力；选题要用他们能理解的语境 |
| 新增观众 | 从推荐流或搜索第一次遇到你 | 决定破圈；需要「零背景知识也成立」的选题 |

操作口径：每条选题过一遍「三层问题」——核心想不想看？偶尔看得懂吗？新增需要多少前置知识？三层全过是理想选题；只过核心的，做好播放量止步于粉丝数的准备。

### 2.2 好选题的三个条件

| 条件 | 解释 | 自检问题 |
| --- | --- | --- |
| 信息增量或情绪价值 | 给新信息、新角度，或强情绪（共鸣、解气、好奇） | 观众看完能说出「我知道了什么 / 感觉到了什么」吗 |
| 可包装 | 能用一句标题和一个封面把好奇心讲清楚 | 现在就能写出 3 个不重复的标题吗 |
| 可执行 | 现有资源做得出，且愿意做 | 拍摄成本、时间与风险能接受吗 |

三个条件缺一个，选题退回库里重做。

### 2.3 选题漏斗：100 比 1

成熟频道的做法：**从 100 个想法里挑 1 个做成视频。** 想法按三个来源混用：

- **内部来源**：你独有的经历、数据、方法论。最难被抄的池子。
- **外部来源**：评论区提问、社区讨论、行业动态、搜索词。需求已被验证，缺的是你的讲法。
- **包装驱动**：先有一个好标题或好封面，再倒推内容。听起来功利，但能过滤掉大量「讲起来有趣、听起来无聊」的选题。

### 2.4 对标分析：验证需求，而不是复制内容

对标的对象是**需求**，不是**内容**。三步：

1. **找对标**：同方向 5-10 个账号，看近 90 天，不看历史名作。
2. **拆爆款**：每个账号挑 3 条高播放，记录：选题角度、标题写法、封面元素、结构与时长、互动数据。填成表格。
3. **找空隙**：被验证的高需求题材里，哪些还没有人能讲出**你的角度**？

一条判据：对标给你的应该是「什么被证明有效」，而不是「必须跟随的模板」——复制内容只会得到同质化。

## 3. 工作流程与步骤

定位是季度级的动作，选题是周级的动作。

**A. 定位（每季度，或每 30 条视频复查一次）**

1. 写一句话定位：**为 [人群] 提供 [价值]，与 [替代品] 不同，因为 [你的独特之处]**。
2. 做受众画像：他们现在在看谁、缺什么、在什么场景下看你的视频。
3. 划内容边界：明确不做什么。写「不做清单」比写「做什么」更能防止漂移。
4. 定更新节奏：频率以「能长期稳定」为准，宁低勿断。

**B. 选题（每周固定一次选题会，30-60 分钟）**

1. 补给：从三个来源各拉 5-10 个新想法进库。
2. 评估：用 §2.2 的三个条件粗筛，不合格的直接删。
3. 包装：合格的选题当场各写 3 个标题、1 个封面草图。写不出就是可包装性不过关。
4. 排序：按「信息增量 × 时效性 × 执行成本」排序，取下周要拍的。
5. 记录：选题、标题、封面、数据都进库，发布的每条都要能回查当初的假设。

## 4. 模板与工具

- [选题库模板](../../templates/topic-bank.md)：字段包括选题、来源、目标受众层、标题候选、封面思路、假设、状态、发布数据。
- 选题评分卡：信息增量 / 可包装性 / 受众重合 / 执行成本，各 1-5 分，总分 ≥14 才立项。
- 对标分析表：账号、近 90 天播放中位数、Top3 题材、标题模式、封面模式、可借鉴点。
- 工具入口见[资源与工具](../../resources/README.md)：平台搜索与创作者后台是最便宜的数据源，第三方工具按需增补。

## 5. 数据与验收标准

- 选题库库存 ≥30 条，每周净增 ≥5 条。
- 候选选题在讨论时能落成「标题 + 封面草图」，落不成的比例应低于 20%。
- 发布后复查：把「预估表现」与实绩并排记录，一个月后回看命中率。命中率是这项能力唯一的计分板。
- 数据异常时的排查顺序：先回查选题与包装（曝光与点击问题），再查前 30 秒（留存问题），之后才怀疑执行细节（见《增长与复盘》§2）。

## 6. 常见错误

1. **把追热点当战略**：热点是弹药不是方向；可以偶尔蹭，不能靠它建频道。
2. **自嗨选题**：选题会里全程讲自己觉得酷的，没人问「观众为什么要看」。
3. **领域频繁跳跃**：推荐系统与观众都靠稳定性建立预期；一个月换三次方向的频道两边都留不住。守领域与做实验的配比参考 80/20。
4. **只服务核心观众**：播放量止步于粉丝数；反过来只追新增流量，核心观众会流失。
5. **不做包装测试就开拍**：标题封面写不出来，往往说明选题本身模糊。
6. **对标抄内容不拆需求**：得到同质化，而不是差异化。
7. **选题库不维护**：想起来才更新，等于没有库。
8. **没有「不做清单」**：什么都做一点，什么都留不下。
9. **以「拍得出来」为第一标准**：做起来最省事的选题，往往门槛也最低。

## 7. 进阶方向

- **选题会制度化**：把每周选题会写进日程；多人团队固定角色（提想法、挑战、包装测试分开）。
- **数据回灌直觉**：用自己频道的点击与留存数据校准「我以为观众想看」；每月统计选题命中率。
- **系列化与产品线**：表现稳定的选题升级为系列（固定结构、固定受众预期），系列再发展为课程或专栏。
- **跨平台选题适配**：同一选题在长视频与竖屏短内容里的表达边界不同；适配规格见《包装与分发》§5。
