# Creator Atlas · 前言

视频创作的方法论从来不缺单点技巧。缺的是把技巧组织起来的骨架，以及一条从「想做视频」到「靠内容稳定产出」的完整路线。

这个仓库针对四个长期存在的问题：

- **方法碎片化，且常被玄学化**：多数内容停在单点技巧（相机设置、剪辑快捷键、涨粉偏方），不成体系。仓库把创作拆成七个方法域，每个环节给出方法、步骤与验收标准。
- **环节之间断链**：定位、选题、脚本、拍摄、剪辑、包装、增长、变现互相牵制，任何一环断了整体都跑不通。仓库按真实创作流程摆放知识，并写明环节之间的交接物。
- **平台机制不透明**：算法传闻满天飞，规则也一直在变。仓库只引用官方文档与可核实来源，标注核实时点，外链逐条核查并交给 CI 复检。
- **AI 正在改写生产方式**：AI 工具改变了脚本、配音、剪辑与素材的用法。仓库收录可用工作流与披露边界，也保留对「人的判断」的强调。

名字取自 creator（创作者）与 atlas（地图集）：为「做视频」画一张尽可能完整的地图。组织原则只有一条：按真实的创作顺序摆放知识。内容中文优先，兼顾国际与国内平台两条线；每篇文档回答一个具体问题，互相引用而不重复。

这是一个持续维护的开源项目，错漏在所难免：欢迎提交 Issue 或 PR 修正与补充，勘误的优先级最高。
