# Creator Atlas · 制作方法

> 不按题材逐类罗列，而是按「怎么做」把全部内容类型整合成 8 类制作方法：每一类抽取共同的理论与方法论要点，再给出各内容类型在其中的变形差异与完整工作流。
> 覆盖范围：口播观点、知识科普、Vlog、美食、剧情、教程、访谈、动画、影视解说、广告片等百余种内容形态，全部并入 8 类制作方法。

每一类页面包含五节：适用类型详解、方法论要点、标准工作流（七个阶段的动作、产出与检查点）、类型工作流变体、常见误区。

## 适用类型全景

百余种内容形态与 8 类制作方法的对照。判断归属时先回答两个问题：**画面从哪里来**、**生产如何组织**；题材不决定归属，制作方式才决定。

| MG 动效与视觉包装 | MG 广告、片头包装 | 动效设计驱动的交付 |
| 企业培训 | 入职培训、合规课程 | 客户交付的知识内容 |
| 雇主品牌与招聘 | 招聘宣传、雇主品牌 | 客户交付的人才内容 |
| 政企专题片 | 汇报片、成果片 | 客户交付的汇报内容 |
| 展会与活动快剪 | 展会快剪、活动集锦 | 客户交付的即时传播 |
| 房产与场地视频 | 房产、场地、酒店 | 以空间展示为核心 |
| 餐饮与门店宣传 | 菜品、门店、探店物料 | 以门店与产品展示为核心 |
| 招商与投资推介 | 招商片、项目推介 | 以项目价值展示为核心 |
| 演出与音乐现场 | 演唱会、livehouse、音乐节 | 现场演出的专业记录 |

## 归类规则

- 竖屏短视频、横屏长视频是分发形态，可能出现在任意一类方法中；分发的通用方法见[《包装与分发》](../methods/packaging.md)。
- 直播、录课等实时形态按主场景归类：以讲述为主进口播，以对话为主进访谈，以演示为主进操作演示。
- 混合形态按主场景判断：一条内容只归一类，次要形态作为该页的变形处理；如口播里插入演示、纪实里插入访谈。
- 边界情形：赛事集锦、游戏二创与影视混剪归素材再创；婚礼与活动记录在个人纪实与商业摄制之间按「是否为客户交付」划分；真人秀按编排程度归剧情表演或实拍纪实。
- 8 类按「画面从哪里来 × 生产如何组织」两问设计，已知内容形态均可归入；未列出的新形态先按两问定位，再决定并入现有方法还是开启新页。
- 直播家族细则：带货直播按「口播加演示」组合处理；无人值守与轮播直播按素材来源归类；赛事与演出转播归商业摄制；慢直播与陪伴型直播归实拍纪实。
- AI 不改变归类：生成画面归动画合成；AI 辅助的其他方法按主场景归类，并按平台要求披露。

## 为什么按制作方法分类

同一个制作方法共享生产流程、技能栈与评价指标；题材会过时，方法相对稳定。按方法学习，一套方法论可以迁移到多个类型；按类型罗列，则大量条目在重复同一件事。这是本手册只保留 8 页的原因。

## 规划

新增内容形态统一并入现有 8 类；出现全新制作方式（如互动视频）时再开新页。见[内容路线图](../meta/roadmap.md)。
