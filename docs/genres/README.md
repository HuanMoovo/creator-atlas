# Creator Atlas · 制作方法

> 不按题材逐类罗列，而是按「怎么做」把全部内容类型整合成 8 类制作方法：每一类抽取共同的理论与方法论要点，再给出各内容类型在其中的变形差异。
> 覆盖范围：口播观点、知识科普、Vlog、美食、剧情、教程、访谈、动画、影视解说、广告片等六十余种内容形态，全部并入 8 类制作方法。

## 八类制作方法

| 制作方法 | 代表类型 | 方法论核心 |
| --- | --- | --- |
| [口播讲述](talking/README.md) | 观点、科普、评论、垂类口播、演讲 | 人格信任与信息效率 |
| [实拍纪实](documentary/README.md) | Vlog、旅行、美食、探店、宠物、亲子、户外 | 真实感与陪伴感 |
| [剧情表演](scripted/README.md) | 喜剧、微短剧、剧情短片、音乐、舞蹈 | 冲突与情绪的编排 |
| [操作演示](demo/README.md) | 教程、游戏实况、拆解、评测、实操演示 | 可复现性与信息组织 |
| [对话访谈](conversation/README.md) | 访谈、播客、圆桌 | 提问与倾听的结构 |
| [动画合成](animated/README.md) | 动画、白板、AI 生成、无人出镜 | 用构造影像替代实拍 |
| [素材再创](editorial/README.md) | 影视解说、混剪、鬼畜、Reaction | 重组既有素材的再叙事 |
| [商业摄制](commercial/README.md) | 广告片、宣传片、发布会、电商视频 | 目标驱动与交付标准 |

## 为什么按制作方法分类

同一个制作方法共享生产流程、技能栈与评价指标；题材会过时，方法相对稳定。按方法学习，一套方法论可以迁移到多个类型；按类型罗列，则大量条目在重复同一件事。这是本手册只保留 8 页的原因。

## 形态说明

- 竖屏短视频、横屏长视频是分发形态，可能出现在任意一类方法中；分发的通用方法见[《包装与分发》](../methods/packaging.md)。
- 直播、录课等实时形态按主场景归类：以讲述为主进口播，以对话为主进访谈，以演示为主进操作演示。
- 每个页面的最小单元是「类型 → 变形要点」；需要更细的题材方法时，回到[方法域](../methods/README.md)按环节取用。

## 规划

新增内容形态统一并入现有 8 类；出现全新制作方式（如互动视频）时再开新页。见[内容路线图](../meta/roadmap.md)。
