# Creator Atlas · 制作方法

> 不按题材逐类罗列，而是按「怎么做」把全部内容类型整合成 8 类制作方法：每一类抽取共同的理论与方法论要点，再给出各内容类型在其中的变形差异与完整工作流。
> 覆盖范围：口播观点、知识科普、Vlog、美食、剧情、教程、访谈、动画、影视解说、广告片等七十余种内容形态，全部并入 8 类制作方法。

## 八类制作方法

| 制作方法 | 代表类型 | 方法论核心 | 工作流骨架 |
| --- | --- | --- | --- |
| [口播讲述](talking/README.md) | 观点、科普、评论、垂类、演讲 | 人格信任与信息效率 | 命题 → 脚本 → 筹备 → 拍摄 → 粗剪 → 精剪 → 发布 |
| [实拍纪实](documentary/README.md) | Vlog、旅行、美食、探店、宠物 | 真实感与陪伴感 | 承诺 → 计划 → 现场采集 → 素材整理 → 结构 → 精剪 → 发布 |
| [剧情表演](scripted/README.md) | 喜剧、微短剧、短片、音乐、舞蹈 | 冲突与情绪的编排 | 剧本 → 排练 → 制片 → 拍摄 → 试映 → 精修 → 系列化 |
| [操作演示](demo/README.md) | 教程、游戏、评测、拆解、跟练 | 可复现性与信息组织 | 目标 → 流程设计 → 录制 → 加速结构 → 复现复核 → 发布 |
| [对话访谈](conversation/README.md) | 访谈、播客、圆桌、连麦 | 提问与倾听的结构 | 嘉宾 → 问题单 → 场地 → 录制 → 提炼 → 切片 → 复用 |
| [动画合成](animated/README.md) | 动画、白板、AI 生成、无人出镜 | 用构造影像替代实拍 | 配音 → 视觉方案 → 资产 → 合成 → 音画 → 审看 → 模板 |
| [素材再创](editorial/README.md) | 影视解说、混剪、鬼畜、Reaction | 重组既有素材的再叙事 | 盘点 → 解说稿 → 采集标记 → 再叙事 → 配音 → 包装 → 合规复核 |
| [商业摄制](commercial/README.md) | 广告片、宣传片、发布会、电商 | 目标驱动与交付标准 | 需求 → 提案 → 制片 → 拍摄 → 后期轮次 → 交付 → 复用 |

每一类页面包含五节：适用类型详解、方法论要点、标准工作流（七个阶段的动作、产出与检查点）、类型工作流变体、常见误区。

## 适用类型全景

七十余种内容形态与 8 类制作方法的对照。判断归属时先回答两个问题：**画面从哪里来**、**生产如何组织**；题材不决定归属，制作方式才决定。

## 归类规则

- 竖屏短视频、横屏长视频是分发形态，可能出现在任意一类方法中；分发的通用方法见[《包装与分发》](../methods/packaging.md)。
- 直播、录课等实时形态按主场景归类：以讲述为主进口播，以对话为主进访谈，以演示为主进操作演示。
- 混合形态按主场景判断：一条内容只归一类，次要形态作为该页的变形处理；如口播里插入演示、纪实里插入访谈。
- 边界情形：赛事集锦、游戏二创与影视混剪归素材再创；婚礼与活动记录在个人纪实与商业摄制之间按「是否为客户交付」划分；真人秀按编排程度归剧情表演或实拍纪实。

## 为什么按制作方法分类

同一个制作方法共享生产流程、技能栈与评价指标；题材会过时，方法相对稳定。按方法学习，一套方法论可以迁移到多个类型；按类型罗列，则大量条目在重复同一件事。这是本手册只保留 8 页的原因。

## 规划

新增内容形态统一并入现有 8 类；出现全新制作方式（如互动视频）时再开新页。见[内容路线图](../meta/roadmap.md)。
