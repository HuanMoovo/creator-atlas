# Creator Atlas · 制作方法 · 动画合成（Animation & Synthesis）

> 定位：画面不来自拍摄现场，而由制作生成。成本结构与实拍相反：时间与人力密集，但不受场地和天气约束，能表达实拍做不到的东西。
> 配套：[《脚本与叙事》](../../methods/script.md)《拍摄与制作》《剪辑与后期》等[方法域](../../methods/README.md)页面。

## 1. 方法与适用类型

动画合成的本质：**用构造的影像替代拍摄**。抽象概念、不可拍之物、想象与示意，都能被画出来、合出来、生成出来。判断题材是否适合这类方法，只需回答一个问题：为什么不用实拍？答案通常是四类中的一种——抽象（没有实体）、规模（拍不到）、想象（不存在）、安全（不能拍）。

它适合解释性、示意性与想象性内容；对「真人氛围」与「即时反应」的依赖越强，越不适合。

| 代表类型 | 方法侧重 |
| --- | --- |
| 科普动画、解释视频 | 信息密度与可视化隐喻 |
| 白板动画 | 手绘过程感与认知引导 |
| AI 生成影像 | 快节奏出片，人工统一风格 |
| 无人出镜（素材+配音） | 效率路线，人格来自声音与选题 |

## 2. 方法论要点

1. **先回答「为什么不用实拍」**。动画的每一秒成本都高于实拍，题材收益必须对得上成本。
2. **风格统一优先于单体精美**。一套贯穿全片的视觉语法（配色、图形、动效规则）比任何一张精修单帧更重要。
3. **声音先行**。先定配音与音效，再按声音节奏作画；动画类内容的节拍锚点在声音上，不在画面上。
4. **成本的杠杆在复用**。元件库、角色符号、模板化转场是产能的来源；「每一帧都是全新手绘」是奢侈品。
5. **信息节拍驱动画面**。每 3 至 5 秒给出一次视觉变化或信息增量，静止画面不宜超过这个窗口。
6. **AI 辅助的正确用法**。生成的是候选，不是成品：批量生成、人工筛选、统一风格，并对 AI 产出做验证与披露。
7. **人格可以后置，但不能缺席**。无人出镜路线里，人格由声音、选题偏好与叙事语气承担。

## 3. 类型变形与差异

| 类型 | 变形要点 |
| --- | --- |
| 科普动画 | 隐喻设计是核心：把抽象关系翻译成可视结构 |
| 白板动画 | 手绘过程感引导注意力；顺序就是逻辑顺序 |
| AI 生成影像 | 出片快、迭代快；人工统一是质量的分水岭 |
| 无人出镜 | 素材可用性与版权是主要约束；效率来自模板化流程 |

## 4. 常见误区

1. **炫技盖过信息**。动效服务于理解，超过需要就是噪声。
2. **风格拼盘**。多种美术风格混用，成片显得廉价。
3. **忽视音频设计**。画面精美、声音敷衍，沉浸感立刻消失。
4. **把动画当便宜实拍**。为省钱选动画，往往产出更差且更贵。
5. **AI 产出不验证**。事实性错误与风格漂移会原样进入成片。
6. **节奏单一**。全程一个速度、一种转场，观众三分钟后失去新鲜感。
