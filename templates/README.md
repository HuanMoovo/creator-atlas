## 使用建议

- 模板是骨架，先用起来再改造；调整时保持字段齐全。
- 团队使用时统一一份，放共享文档，避免版本分裂。
- 与[制作方法](../docs/genres/README.md)配合：先定制作方式，再取用对应模板。
