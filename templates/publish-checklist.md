# Creator Atlas · 清单与模板 · 发布前检查清单

> 用法：发布前逐项打勾，全过再点发布按钮。任何一项存疑，宁可延后一天。

## 内容

- [ ] 开头 3 秒完成钩子；承诺与内容兑现
- [ ] 全片无口误硬伤；事实与数据已核对
- [ ] 结尾有收束与行动引导

## 技术

- [ ] 音画同步抽查通过；响度统一，移动端外放测过
- [ ] 字幕全文校对（错别字、断句、人名）
- [ ] 导出规格符合目标平台要求

## 包装

- [ ] 标题定稿（经过多选一）；封面在手机小图上可读
- [ ] 标题与封面信息互补，不重复

## 合规

- [ ] 音乐、素材、字体的授权状态已确认
- [ ] 涉及商单或带货：广告标识与披露已加
- [ ] 人物出镜已获同意

## 发布设置

- [ ] 简介、话题与章节就绪；置顶评论准备好
- [ ] 发布时间在受众活跃时段
- [ ] 发布后 48 小时回填[复盘模板](retro.md)
